System Architecture & Heuristic Specifications

1. Point-in-Zone Reference

Object locations are evaluated using the bottom-center ground contact point ((x1+x2)/2, y2). This minimizes false positives compared to bounding box center or top coordinates.

2. Temporal Confirmation & Debouncing

Potential intrusions must be confirmed across 3 consecutive frames inside the danger polygon before an event is logged, filtering out single-frame tracking noise.

3. Alert Deduplication & Cooldown

While an object continuously remains inside a restricted zone, subsequent duplicate alerts are suppressed for a cooldown period of 10.0 seconds.

4. Barrier State Safety Protocol

When the barrier state is UNKNOWN, crossing entries are logged as POTENTIAL_CROSSING_ALERT with Medium risk and explicit notices that automated closed-barrier violation status cannot be confirmed.
